Google Apps Script Setup Guide
  1. Open your target Google Spreadsheet.
  2. Navigate to Extensions > Apps Script.
  3. Paste the provided `Code.gs` handler script and click Save.
  4. Click Deploy > New deployment.
  5. Select type Web app, set Execute as: Me, and Who has access: Anyone.
  6. Copy the resulting Web App URL and paste it into the field on the left.
